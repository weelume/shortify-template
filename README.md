# Shortify · 短视频创作与剪辑

独立的双语响应式官网模板，十二个页面，包含本地短视频、轮播、滚动高亮、创作流程、FAQ、演示日历与联系表单。

完整使用、运行、停止、修改和验收说明在 [.tpl/README.md](.tpl/README.md)。协议入口为 [.tpl/template.json](.tpl/template.json) 与 [.tpl/project.json](.tpl/project.json)。素材与许可边界见 [.tpl/docs/LICENSE.md](.tpl/docs/LICENSE.md)。

`pnpm install --frozen-lockfile` → `pnpm dev`，默认端口 43320。检查使用 `pnpm typecheck`、`pnpm lint`、`pnpm test`、`pnpm build`。无数据库、密钥或外部预约服务。
