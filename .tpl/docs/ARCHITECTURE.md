# 架构

应用采用 Next.js、React、TypeScript 与 Framer Motion，依赖锁由包管理器维护。`src/app/[[...slug]]/page.tsx` 按页面注册选择动态模块，未知路径返回 404。`config/routing.ts` 负责挂载点和双语路径，不绑定特定域名。

品牌配置、双语内容、主题、公共组件、页面组合及路由入口分别维护。`host.tsx` 提供可选品牌、Logo、平台入口与页脚注入；通用页面不依赖消费方工程。导出 `./template` 和 `./host` 支持消费方复用；独立站使用同一份页面源码。

`Video` 使用可见性控制播放，主动取消播放不报成素材错误，真正失败显示控件与错误语义。`Process` 为键盘可操作的标签切换，`Carousel` 支持自动轮播、暂停、拖拽和循环复位。`ScrollWords` 按滚动区间逐词点亮。`Shell` 负责原生 dialog 菜单、焦点恢复、背景锁定和路由范围样式清理。减少动态效果由 MotionConfig 和 CSS 共同处理。

表单和日历没有持久化与发送逻辑。浏览器原生字段校验负责输入格式，成功状态明确表示仅本地校验，不以模拟成功代替网络请求。
