# 许可与素材权利

这是针对 https://shortify.framer.ai/ 的独立前端实现。独立编写的应用源码仅用于本模板交付与评估；本仓没有获得参考站整体、商标、人物肖像、视频、照片或插图的商业再分发授权，因此采用 restricted 状态，`redistributionAllowed=false`、`listed=false`。公开 Git 可追溯不等于素材商业授权。

参考视频、照片、人物、品牌与插图保留原权利人的权利，来源见 `.tpl/asset-sources.json`。不得把原站的虚构人物名、评价、播放量和品牌展示解释成真实客户关系或保证。商业使用前应自行取得相应授权，或替换为已授权素材并重新验证。

Poppins 使用 SIL Open Font License，许可随字体保存在 `public/templates/shortify/fonts/Poppins-OFL.txt`。MiSans 使用小米发布的字体知识产权许可协议，来源与限制见 `fonts/misans/LICENSE-SOURCE.md`，不是 SIL OFL。字体文件不单独出售；遵守各自的分发条件。

Next.js、React、Framer Motion 与开发工具遵守各自的第三方许可。工具许可不能推导为参考素材或整套模板的许可。使用者应在正式分发前审阅源站与素材权利要求。
