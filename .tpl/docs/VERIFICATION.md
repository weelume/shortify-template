# 验收方法

安装使用冻结锁文件。依次执行 `pnpm typecheck`、`pnpm lint`、`pnpm test`、`pnpm build`。协议检查执行 `pnpm tpl:check`，它检查仓库和元数据，不证明页面视觉或交互已通过。

浏览器按 PC 1440×1000、iPad 834×1180、H5 390×844 和 320px 窄屏检查所有页面与语言：无坏图、真实横向溢出或重复主标题；切换语言保留同页、查询参数和锚点；菜单支持 Escape、背景锁定和焦点恢复；FAQ、流程、轮播、视频播放和本地表单语义正确。

截图以实际解码尺寸登记。动效需要实际触发并比较多个时刻；循环检查边界与暂停恢复，拖拽检查释放，视频检查时间推进，滚动高亮检查上下滚动。不能以路由 200 或静态截图代替动态验收。检查原生滚动、滚动条主题与路由清理。

实际执行结果见 `.tpl/reports/`；报告必须与源码摘要关联。未执行项和差异要明确记录，不能把部分通过描述为完全一致。
